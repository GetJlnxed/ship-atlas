# ATLAS — каталог кораблей Star Citizen

Самостоятельное приложение на Vue 3 + Vite. Каталог кораблей, гибкие фильтры и сравнение; остальные разделы FleetYards не воспроизводятся.

## Запуск

Готовая версия находится в `dist/`. Откройте `start.cmd`, затем http://127.0.0.1:4173/ . Окно запуска должно оставаться открытым. Альтернатива: `node server.mjs`. Сервер слушает только локальный компьютер. `start.ps1` может запускать сервер скрыто и открывать сайт.

В этой среде используется установленный Node 24. Для переноса достаточно Node 22.12+ и папок `dist/`, файла `server.mjs`. Готовой версии не нужны npm или исходные данные для запуска.

Для разработки:

```text
npm install
npm run dev
npm run build
npm test
npm run test:ui
```

В исходной среде npm был установлен локально: `node scripts/package/bin/npm-cli.js <команда>`. Файл `package-lock.json` фиксирует версии зависимостей.

## Возможности

- Карточки и таблица, поиск, сортировка, страницы по 24 записи.
- Быстрые фильтры по производителю, типу техники, готовности, грузу, минимальному экипажу и цене.
- Конструктор вложенных групп И / ИЛИ / НЕ для каждого импортированного поля. Числа: сравнения и включительные диапазоны; текст: совпадение, подстрока, список через `|`; логические значения; наличие данных.
- Для пропусков доступны «исключить», «включить», «только неизвестные». Ноль и false не считаются пропусками.
- Массивы проверяются по одному, всем или ни одному элементу; отрицательные операторы требуют отсутствия совпадений. Разные условия по полям массива проверяются независимо: они могут относиться к разным компонентам. Число элементов доступно в отдельных `.count` полях; повторяющиеся значения в списках свернуты.
- Сравнение произвольного количества моделей с горизонтальной прокруткой, режимом «только различия», поиском строк и всеми подробными полями. Неизвестное значение показывается как «—». Подсветка означает различие, а не универсально лучшее значение.
- Сохранение именованных воронок и текущего состояния в localStorage, JSON-импорт/экспорт, ссылки с параметрами в URL-фрагменте, CSV выборки и сравнения. Нет аккаунтов или серверной синхронизации.
- Ссылки на источники и происхождение общих полей. Параметры игровых компонентов отделены от данных RSI.

## Данные

Снимок от 23.10.2026: 248 моделей из FleetYards и 11 дополнительных записей из RSI, всего 259. Дополнения преимущественно представляют специальные издания и комплекты; они не выдаются за 11 новых базовых корпусов. Совпадения определяются по RSI ID, а не приблизительному названию.

Источники:

- https://api.fleetyards.net/v1/models?perPage=240&page=1 — постраничный список с проверкой totalCount и уникальности.
- `/v1/models/{slug}` — подробная карточка, доки и совместимые носители.
- `/v1/models/{slug}/hardpoints?source=game_files` — установленное игровое оборудование с вложенными слотами.
- `/v1/models/{slug}/positions` — позиции экипажа.
- https://robertsspaceindustries.com/ship-matrix/index — официальная матрица и дополнения.

Исходные ответы сохранены в `data/raw/`, пользовательский набор — `public/data/catalog.json`. Служебные изображения и тексты описаний не превращаются в числовые характеристики. После очистки оставшиеся поля доступны через уровни «Основные», «Расширенные», «Все, включая служебные». Внутренние ключи, теги, флаги записей, имена слотов и ещё не расшифрованные поля видны только на последнем уровне. Подписанные инженерные настройки доступны в расширенном режиме. Компоненты RSI сгруппированы по назначению; количество компонентов отделено от служебного числа записей в исходном массиве. Переводы и классификация находятся в `src/field-presentation.js` и применяются при каждой сборке данных. Единицы непрозрачных параметров не угадываются. Исходные ключи и значения сохранены: ранее сохранённые воронки работают, уже выбранные поля остаются в конструкторе при смене уровня. Длинные списки раскрываются по нажатию.

В сравнении кнопка «Выбрать характеристики» открывает поиск и выбор отдельных строк или групп. Можно восстановить базовый набор, выбрать/снять найденные поля и посмотреть только выбранные. Поиск и уровень в панели выбора не меняют уже выбранный набор. Он хранится отдельно от воронок в `atlas-comparison-fields-v1`, включая намеренно пустой набор. Таблица и CSV используют выбранные поля с учётом поиска по таблице и переключателя «Только различия».

Интерфейс использует плавные переходы окон, карточек, панели сравнения и уведомлений. Настройка системы «уменьшение движения» отключает анимации и плавную прокрутку.

Общие показатели берут FleetYards, при отсутствии — RSI. Минимальный экипаж берётся из отдельного поля min_crew RSI, поскольку одно поле crew.value FleetYards не определяет минимум и максимум. Значения RSI могут отставать от игры. Издания, отсутствующие в FleetYards, не получают выдуманные игровые компоненты.

Суммарные HP щитов и брони — сумма соответствующих числовых параметров установленных компонентов. Количество оружия и ракет учитывает вложенные установленные слоты с дедупликацией по ID слота. Это штатное оснащение, а не симулятор пользовательского loadout. Расчётные боевые показатели интерфейса FleetYards, например sustained DPS с нагревом и распределением питания, здесь не воспроизводятся как неподтверждённые числа; их исходные компоненты доступны фильтрации.

## Отбор и показ характеристик

При сборке данных из списка выбора удаляются полностью пустые поля, поля с одним известным значением во всём снимке, поля с данными только у 1–3 моделей и точные дубликаты. Учитываются пропуски, порядок элементов списка не влияет на сравнение. В группе дубликатов приоритет имеют общие показатели, затем поля без служебной маркировки. Текущий снимок: 4070 → 1573 поля (2497 исключены). Причины непересекающиеся в отчёте: 34 пустых, 2217 постоянных, 95 редких после исключения постоянных и 151 дубликат оставшихся полей.

Правила применяются при каждом обновлении, поэтому ранее неинформативное поле может вернуться при появлении новых данных. Сырые ответы и значения сохраняются; metadata исключённых полей находится в archivedFields исключительно для совместимости с сохранёнными условиями. Такие условия отмечаются как архивные и продолжают фильтровать без изменения смысла. В новых условиях, списках характеристик, сравнении и CSV исключённые поля не предлагаются. Старый выбор дубликата в сравнении переводится на основное поле; остальные исключённые поля убираются из набора сравнения. Поиск по прежнему ключу дубликата находит основную характеристику.

Паспорт корабля открывается обзором: до восьми ключевых показателей, отдельный блок брони с энергетическим и физическим Deflection и пять разделов. Deflection отображается в исходных значениях без предположений о единицах; при отсутствии данных показан прочерк. В разделе выбирается одна группа; список и результаты поиска ограничены 12 строками на страницу. Поиск проходит по всем разделам выбранного уровня. Общий справочник характеристик также имеет группы, поиск и страницы по 12 строк.

## Обновление

```text
npm run data:update
npm run build
```

Импорт сначала загружает все страницы и детали во временную директорию, проверяет полноту, затем сохраняет резервную копию предыдущего снимка и пересобирает каталог. При сетевой ошибке текущая версия не заменяется. Фоновое обновление не включено. Отдельный `node scripts/cache-images.mjs` кэширует иллюстрации; затем выполните `npm run data:build` и `npm run build`. Содержимое `data/raw/import-manifest.json` фиксирует дату импорта.

## Проверка и ограничения

Автоматические проверки покрывают семантику пропусков, числовые границы, массивы, вложенные группы, защиту CSV от формул, полноту данных, реальные сценарии Vue: поиск, быстрые фильтры, сравнение, сохранение, страницы и карточку корабля. Production-сборка проверяется отдельно.

Визуальная проверка в настоящем браузере в текущей сессии заблокирована политикой инструмента браузера. HTTP-доступность локального сервера и компонентные сценарии проверены отдельно; они не являются подтверждением визуального отображения. Внешний хостинг не настроен: инструменты публикации Sites в сессии отсутствуют. `dist/` можно разместить на обычном статическом хостинге; локальный сервер поддерживает сжатую версию данных.

Проект не связан с Cloud Imperium. Star Citizen и иллюстрации принадлежат соответствующим правообладателям; данные атрибутированы FleetYards и RSI. Предназначен для личного некоммерческого использования.
## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет и собирает сайт при push в `main`, затем публикует `dist/` на GitHub Pages. В Settings → Pages выбран источник GitHub Actions. Сборка использует относительные пути и подходит как для адреса `/ship-atlas/`, так и для корня домена.

В репозитории хранится готовый снимок `public/data/catalog.json` и исходные публичные данные для проверки. Обновление снимка выполняется отдельно через `npm run data:update` и `npm run data:build`, после чего изменения коммитятся. Сборка сайта сама данные не обновляет.
